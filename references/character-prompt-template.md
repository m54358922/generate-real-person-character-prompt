# 真人角色母本与多视图提示词模板

## 用法

先填写人物母本，再选择三视图或四格设定图布局。方括号里的内容要换成项目内容，没用到的字段直接删掉。

先生成干净的角色母本，再让人物进入场景或剧情。每次只改一个变量，并保留版本号。

## 1. 角色母本

```text
生成原创真人角色 C01：[年龄]岁，[国籍][性别]，[职业/身份]。

基本体态：身高约[身高]厘米，[体型]，[肩膀、腰部、腿部或四肢特征]。站姿[自然/挺拔/轻微含胸]，身体比例真实。

面部特征：[脸型]，[眉毛特征]，[眼睛大小和神态]，[鼻型]，[嘴部特征]。
肤色为[肤色]，保留[毛孔、细纹、晒斑、痣、轻微油光等真实皮肤细节]，皮肤不过度磨皮。

发型与修饰：[发色][发型]，发量[多少]，头顶[蓬松/服帖]，[鬓角、发际线、白发等细节]。留[胡须/无胡须]。

角色气质：[职业气质和性格]。眼神[专注/温和/冷静]，表情[自然微笑/平静/克制]，不做夸张网红表情。

服装：上身穿[外套或上衣的颜色、材质、版型和使用痕迹]，内搭[颜色、领型、材质]；下身穿[裤子颜色、版型和褶皱]；脚穿[鞋子类型、颜色和使用痕迹]。

固定配饰：[包、眼镜、帽子、麦克风或其他身份标志]，写清佩戴位置和方向。没有[不需要的饰品]，不出现明显品牌 Logo。

必须保持的视觉锚点：[脸部轮廓]、[发型特征]、[体型或站姿]、[固定服装]、[固定配饰]。
```

## 2. 三视图设定图

```text
使用角色 C01 的固定母本，生成同一名真人角色的全身三视图：正面、[左侧面/右侧面]、背面。

三张图必须保持完全相同的面孔、年龄感、发型、发色、体型、服装颜色、服装结构、肤质和固定配饰。

采用中性站姿，双脚自然站立，双臂自然下垂，手里不拿东西，背景为中性浅灰或纯白无缝摄影棚背景，光线柔和均匀，主体居中，全身完整入画。

正面图重点展示：[脸部识别点、服装正面和胸前配饰]。
侧面图重点展示：[鼻梁轮廓、身体比例、服装侧面和配饰位置]。
背面图重点展示：[发型后部、服装背面、背带、裤型和鞋子]。

保持正常人体比例、真实皮肤纹理和自然服装褶皱。三个角度保持相同曝光、色温、人物比例和背景风格。
```

## 3. 四格角色设定板

```text
使用角色 C01 的固定母本，生成同一名真人角色的四格角色设定图。

画面一：[头像/胸口以上/半身]，[正面或指定角度]，重点展示[脸型、眼神、皮肤纹理、发型]。
画面二：全身正面图，双脚自然站立，双臂自然下垂，展示完整服装和固定配饰。
画面三：全身[左侧面/右侧面]九十度站姿，展示[鼻梁、体型、服装侧面和配饰位置]。
画面四：全身背面图，展示[发型后部、服装背面、背带、裤型和鞋子]。

四个画面中的人物必须是同一个人。保持面孔、年龄感、发型、体型、肤质、服装、配饰、背景风格、曝光和色温一致。
```

## 4. 摄影与画面参数

```text
中性[浅灰/白色]无缝摄影棚背景，柔和均匀布光，真实全画幅相机摄影，[镜头焦段]镜头效果，正常人体比例，真实皮肤纹理和自然阴影。
服装保留[褶皱、褪色、磨损、使用痕迹]。画面干净，主体居中，背景不加入剧情场景和额外道具。
```

## 5. 一致性与禁止项

```text
优先保持参考图和角色母本中的固定特征。禁止改变脸部结构、年龄感、发型、发色、体型、服装颜色、服装结构和固定配饰位置。

禁止出现：额外人物、额外道具、复杂场景、食物、桌椅、文字、水印、品牌 Logo、3D、插画、动漫、游戏建模、时尚模特比例、明星脸、过度磨皮、网红滤镜、夸张表情、换脸、换装、年龄变化、身材变化、发型变化、配饰变化、畸形手脚和多余肢体。
```

## 6. 生成前检查

```text
[ ] 已填写年龄感、身份、体型、面部、发型、服装和固定配饰
[ ] 已定义每个画面的景别、角度和展示重点
[ ] 头像、三视图和四格设定板的布局没有混淆
[ ] 侧面和背面没有强行描述看不见的表情
[ ] 所有画面使用同一背景、光线、曝光和色温
[ ] 已删除空的方括号和不需要的字段
[ ] 已写清换脸、换装、文字、水印和肢体错误等禁止项
```
